# Intentionally empty.
#
# This file is the pip manifest that `sam build` uses for EVERY Lambda
# function (they all share CodeUri: . + BuildMethod: python3.10). It is kept
# empty on purpose so functions build as pure source with NO bundled wheels —
# all runtime dependencies are provided by the shared DepsLayer.
#
# Why: if real deps lived here, a non-Docker build on Windows would bake
# Windows binaries (cryptography, bcrypt, pydantic-core) into each function
# package, where they shadow the layer's Linux wheels and crash at import.
#
#   - Deployed dependencies -> layer/requirements.txt  (source of truth)
#   - Local dev dependencies -> requirements-dev.txt
